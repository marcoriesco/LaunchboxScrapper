🎯 Funcionalidades Principais
1. Interface inicial (GUI)

A interface terá duas frentes principais:

🔎 Busca manual
Select obrigatório de Plataforma
Select opcional de Game
Regras:
Se apenas a plataforma for selecionada → buscar todos os jogos dela
Se um game for selecionado → buscar apenas aquele jogo
⚙️ Scrape automático
Usuário seleciona uma plataforma
O sistema faz scraping automaticamente de todos os jogos dessa plataforma
⚙️ Página de Configuração

O sistema deve permitir configurar:

📄 Leitura dos arquivos:
es_systems.cfg

🎮 Lógica de Scraping
Listar plataformas com base na pasta /roms
Para cada plataforma:
Buscar config correspondente no es_systems
Se não existir → retornar erro
A partir do es_systems, extrair:
Extensões de arquivos (ex: .zip, .nes, etc)
Listar jogos da pasta
Fazer scraping jogo por jogo via LaunchBox
